# 登录、语言与找回密码

## 登录

打开 `http://<服务器IP>/`（HTTPS 则为 `https://域名/`）。必须和安装时 `config.env` 里的 `PUBLIC_HOST` 是同一套地址。对不上会提示 **跨站认证请求被拒绝**，改法见 [离线安装 · 访问地址](offline.md#访问地址云服务器必看)。

1. 输入 **账号或邮箱** 与密码。
2. 登录页文案、背景、Logo 可由超级管理员在 **平台管理 → 登录页配置** 修改。
3. 账号、邮箱在系统内唯一；也不可与另一用户的邮箱/账号互相冲突。

## 切换语言

登录后顶栏选择 **简体中文** 或 **English**。偏好会保存在浏览器中，刷新后仍有效。

## 忘记密码

登录页点击 **忘记密码**：

1. 输入账号或邮箱。
2. 若该用户存在且已启用，系统生成随机 12 位密码并发送到 **用户邮箱**。
3. 无论账号是否存在，页面都提示「若账号存在则已发送」，避免枚举账号。

{% hint style="warning" %}
必须先在 **平台管理 → 邮件配置** 配好可用 SMTP，忘记密码才会真正改密并发信。SMTP 未就绪时不会改密码。

超级管理员自己忘记密码、又没有可用邮箱时，在服务器安装目录执行：

```bash
sudo ./reset_admin_zh.sh
```
{% endhint %}

请事先在 **个人中心** 填好可收信的邮箱。

## 退出

顶栏头像 → **退出登录**。

## 现场 App

App 走同一套 `/api/v1`，登录时传 `"client": "mobile"`。用法和接口清单见 [App 接口](../appendix/app-api.md)。网页登录不要加这个字段。
