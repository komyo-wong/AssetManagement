# 端口与数据目录

{% hint style="warning" %}
网页登录账号与密码、网关 MQTT 账号与密码 **以安装结束时终端打印的内容为准**。说明书不列出默认账号、密码和 Topic 名称。投产请尽快在 **个人中心** 修改管理员密码，并限制谁能登录服务器查看 `config.env`。
{% endhint %}

## 网页

浏览器访问安装结束界面打印的地址（一般为 `http://<PUBLIC_HOST>/`）。`PUBLIC_HOST` 安装时若留空，则取第一块网卡 IPv4；云主机请改成公网 IP 或域名，并同步 `AUTH_ALLOWED_ORIGINS`，否则登录会被拒绝。详见 [离线安装](../install/offline.md)。

## 网关 MQTT

地址一般为 `mqtt://<PUBLIC_HOST>:1883`。用户名、密码以及网关应使用的 Topic，见安装结束界面，或在网页 **网关管理 → 接入配置** 中复制。

## 基础设施（仅本机回环，不对公网）

| 端口 | 服务 |
| --- | --- |
| 5432 | PostgreSQL |
| 6379 | Redis |
| 8080 | API |
| 8081 | Worker 健康检查 |

网页 80；HTTPS 时 443。网关需要访问的是 **1883** 与网页端口。

## 库与中间件

库名、中间件账号写在服务器 `config.env` 中，安装结束界面也会提示数据目录位置。默认数据目录为 `/var/lib/asset-management`。
