# 网关接入参数

在 **设备与空间 → 网关管理** 中创建网关后，打开 **接入配置**。Broker 来自项目里的「本机 Broker」。

**按页面显示的字段写入网关即可**。每台网关用自己的账号，不要改成安装时的平台账号。创建或保存接入配置后，本机 Broker 会登记这对账号：

| 字段 | 说明 |
| --- | --- |
| host | 安装时的 `PUBLIC_HOST`（服务器局域网 IP 或域名） |
| port | 一般为 `1883` |
| usr / pw | 接入配置中的账号密码 |
| clientId | 页面生成或自定义 |
| 发布 Topic | 接入配置中的发布项（扫描/业务） |
| 订阅 Topic | 接入配置中的订阅项（下行） |
| qos | 按固件，常见 0 |

下行包括：蜂鸣、墨水屏、盘点开始/结束。账号密码可在接入配置中修改后保存。

## 防火墙

网关所在网络必须能访问服务器 **1883**。网页端口给浏览器用，网关不需要访问 80 才能上报。
