# 我的通知

路径：**告警中心 → 我的通知**。

## 渠道

- **邮箱**：需超级管理员先在 **平台管理 → 邮件配置** 启用 SMTP。可填账号邮箱或其它地址。
- **Webhook**：向 URL POST JSON。

## 订阅

勾选 **告警触发** / **告警恢复**，选最低级别、推送间隔：

- 仅一次：开单与恢复各推一次
- 或每 5 分钟 / 15 分钟 / 1 小时等，在未恢复期间重复提醒

高级：静默时段、CRITICAL 仍推、按规则类型过滤。页面下方有最近投递记录（已发送 / 失败 / 待发送 / 已跳过）。已跳过多为抖动抑制。
