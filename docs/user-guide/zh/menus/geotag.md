# 对接 GeoTag

路径：**平台管理 → 对接 GeoTag**。仅 **超级管理员** 可见。

接通他们云上的 GPS 标签。不要和场内蓝牙平面图混在一起。

开通时填写：API 地址、企业号、对方平台公钥。系统自动生成密钥，页面展示系统公钥。复制提供给GeoTag服务商或自行到GeoTag企业平台保存。

**Webhook 可选：**

- **勾选**：页面用公网 IP（可改）和端口拼出回调地址。把该端口在路由器/防火墙上转到本机 API，并点「测试联通性」。对方把位置推到这个地址，落成本地轨迹。
- **不勾选**：后台定时向他们云的 `/device/getHistory` 拉点写入本地库。网页只查库，不现场打云。

本机先验证可以把 API 地址填 `mock`：不连他们云，已绑定资产的设备名都会出现；也可用「试写入一条」往轨迹库插点。

接通并刷新后，侧栏出现 **GeoTag 管理**（角色需勾选 **GeoTag 管理** 权限）：

- **位置地图**：每台设备最后一条轨迹点；可按资产类型筛选；左侧卡片显示最近地址
- **设备**：已绑定信标、且能出现在 GeoTag 列表里的设备
- **轨迹**：按设备看已存的点（一个点也算轨迹）

底图默认 **OpenStreetMap**（免费，可开 3D）。位置地图和轨迹页左上角可切换：

- OpenStreetMap：免费，可 3D
- Esri 街道图：免费，仅 2D
- CARTO：仅 2D，需 Key（https://carto.com/basemaps/）
- MapTiler：可 3D，需 Key（https://cloud.maptiler.com/account/keys/）

没存 Key 时切到 CARTO / MapTiler 会提示去申请，并到本页填写。Key 要先保存在本页，地图页才能切过去。
