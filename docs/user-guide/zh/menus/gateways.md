# 网关管理

路径：**设备与空间 → 网关管理**。

## 新建网关

1. 填写名称；编码默认为 4 位数字，可修改。
2. 选择所属区域后，可在平面图上点安装位置。
3. 可选填写约 1 米处的校准 RSSI，用于估距。
4. Client ID 可留空，由系统生成。
5. 点 **创建并生成接入配置**，得到 host、port、账号、密码、clientId、发布/订阅 Topic、QoS。

账号密码可在接入配置中修改后保存。Broker 来自项目 MQTT 连接（离线安装后即为本机 Broker）。把这些参数写入网关即可上报。

字段说明见 [网关接入参数](../appendix/gateway.md)。
