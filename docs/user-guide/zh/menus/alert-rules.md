# 告警规则

路径：**告警中心 → 告警规则**。规则可启用 / 停用。命中后生成 [告警事件](alert-events.md)，并可推到 [我的通知](notifications.md)。

| 条件 | 阈值含义 |
| --- | --- |
| 信标离线 | 超过 N 秒未被扫描 |
| 网关离线 | 超过 N 秒无心跳/上报 |
| 资产离线 | 已绑定信标超过 N 秒未见扫描 |
| 电量过低 | 电量百分比 ≤ 阈值（无百分比时按档位估算） |
| 信号过弱 | 在线时平滑 RSSI 弱于阈值（更负，如 -85 dBm） |
| 盘点结果 | 盘点结束推送；覆盖率低于阈值 WARNING，否则 INFO |
