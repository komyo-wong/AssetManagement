# 总览

路径：**总览**（登录后默认首页，标签固定）。

用于看现场是否健康，作业请点进对应菜单。页面会自动刷新。

## 指标卡片

| 卡片 | 含义 |
| --- | --- |
| 资产台账 | 未归档资产数量；提示未绑定信标台数 |
| 现场在线 | 已登记信标 + 网关中当前在线的数量与在线率；未绑定资产不计入现场 |
| 离线设备 | 离线资产 + 离线网关 |
| 未处理告警 | 状态为「待处理」的告警 |

## 待办

把需要处理的事项按原因归类（离线、未绑定、低电、告警），点击可跳到资产台账、现场或告警中心。没有待办时显示正常状态。

## 离线设备

分列 **离线资产** 与 **离线网关**。栏内可滚动，空状态会收矮。

## 底部三栏

各显示最近约 6 条：

1. **最近出现**：最近被扫描到的资产/信标
2. **网关状态**：网关在线/离线
3. **最近盘点**：最近的盘点会话

可从总览跳到 **平面图**、**资产状态**、**告警中心**。
