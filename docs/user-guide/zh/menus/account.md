# 个人中心

路径：顶栏头像 → **个人中心**（侧栏默认不展示）。

## 基本资料

- **昵称**、**邮箱**（用于登录和找回密码）。超级管理员也可在此改邮箱。
- **头像**：小于 240KB 的图片，可恢复默认。

账号（用户名）在本页不可改。

## 修改密码

填写当前密码、新密码（至少 8 位）并确认。

## 告警提醒

设备离线或新告警时：

- **弹窗提示**（默认开）
- **声音提醒**（默认开；浏览器需先点击页面才能播音频）

自定义提示音：mp3 / wma，≤300KB。Chrome / Safari 对 mp3 更稳；wma 可能无法播放。可试听、恢复默认音。
