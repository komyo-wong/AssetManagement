# 资产管理

路径：**资产中心 → 资产管理**。列表约每 3 秒自动刷新。

一条资产属于某个 **资产类型**。绑定信标后，按 [在线阈值](presence-ttl.md) 判定在线/离线。未绑定显示「未绑定」，不能按信标定位。

创建时名称必填；可用信标 MAC 作为编码。支持按编码/名称/网关/信标、类型、在线状态、协议、是否已绑定筛选。新建/编辑时可勾选 **墨水屏** 并选择 2.13 寸或 2.8 寸（广播识别不到 2.8 寸时必须手选，列表才会出现「改屏」）。也可从图库选一张常见资产图，或上传不超过 100KB 的图片；列表显示小预览，鼠标悬停会放大。

## 绑定与解绑

- **绑信标**：选择已登记、且未绑定到其他资产的信标。
- **解绑**：解绑后无法继续通过该信标定位。已绑定信标必须先解绑才能在信标管理中删除。

## 蜂鸣（寻找）

对已绑定信标的资产下发蜂鸣：短响（约 3 次）、长响（约 10 次）、停止。若信标近期没有明确的最近网关，会向附近网关尝试下发。

## 墨水屏改屏

识别为墨水屏的 GeoTag，或在资产上勾选了墨水屏的，可 **改屏**：选屏型、模版、横/竖屏，也可上传图片或在预览上手写，再下发。必须在信标上配置解锁码，未配置则拒绝下发。可指定首选自研网关；HCBG 不支持改屏。再次打开会恢复上次下发的画面或本机未下发草稿；原图只保留压缩预览。
