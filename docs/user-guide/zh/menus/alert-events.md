# 告警事件

路径：**告警中心 → 告警事件**。约每 5 秒刷新。规则命中后 **立即开单**（与是否发邮件无关）。

| 状态 | 含义 |
| --- | --- |
| 待处理 | 新开单 |
| 已确认 | 已看到，仍可继续处理，停止重复催促 |
| 已关闭 | 人工结案，可触发恢复通知 |

级别：提示 / 警告 / 严重。可按标题、说明、状态、级别筛选。

常见标题：资产离线、网关离线、信标离线、电量过低、信号过弱、盘点结果。

邮件 / Webhook 在 [我的通知](notifications.md) 中另配。
