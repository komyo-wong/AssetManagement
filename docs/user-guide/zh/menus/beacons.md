# 信标管理

路径：**设备与空间 → 信标管理**。

信标数据来自网关扫描。**只有事先登记过的 MAC 才会入库**（支持冒号、横线或 12 位连续十六进制）。

- 添加单条，或下载 CSV 模板后 **导入**（已存在的 MAC 会跳过）
- 筛选：绑定状态、在线、电量、协议
- **历史信号**默认约最近 2 天（同一网关约 30 秒记一点）；**历史状态**约最近 30 天（扫描上线、超时下线、网关离线）
- 绑定/解绑也可在本页操作
- 已绑定资产的信标必须先解绑再删除；批量删除会跳过已绑定项

电量协议默认 **自动识别**，仅异常时再手选。扫描可能把 GeoTag 墨水屏标为可改屏（E-lnk 或 ZA25GM2D）；同名前缀的 Find My 不会。可在改屏时手选屏型。
