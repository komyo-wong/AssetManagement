# 盘点管理

路径：**资产中心 → 盘点管理**。

对选定网关下发点名：这些网关进入点名扫描，结束后自动恢复日常扫描。

1. 点 **开始盘点**。
2. 至少选择一台执行网关。
3. 范围：全部资产 / 按资产类型 / 指定资产。
4. 设置倒计时（分钟）。
5. 开始后向网关下发点名；倒计时结束或手动结束后恢复日常扫描。

{% hint style="info" %}
只有 **本次选中的网关** 的上报会计入该盘点。全部点到会自动结束。
{% endhint %}

进行中可看覆盖率、提前结束。结束后可看报表（已点到 / 未点到 / 未绑信标），导出 CSV，或删除报表。

可在告警规则中配置 **盘点结果**：覆盖率低于阈值发警告，否则为提示（需在「我的通知」订阅）。
