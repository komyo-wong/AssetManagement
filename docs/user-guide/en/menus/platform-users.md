# Users

Path: **Platform Administration → Users**. **Super admin only**.

Operate other accounts: username, display name, email, platform roles, activate/suspend, reset password (min 8 characters on create).

{% hint style="warning" %}
**The super admin and protected accounts** are view-only here. Change the super-admin email/password in [Account](account.md). Username and email are unique and must not collide (login accepts either). Username cannot be changed after create.
{% endhint %}
