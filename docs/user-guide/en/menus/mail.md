# Mail settings

Path: **Platform Administration → Mail settings**. **Super admin only**.

Global SMTP for **Forgot password** and email notification channels. Host, port, username, password/app password, from-address. SSL (often 465) or STARTTLS (often 587). Send a test message. If SMTP is not ready, forgot-password does not rotate the password.
