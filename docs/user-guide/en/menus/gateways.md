# Gateways

Path: **Devices & Space → Gateways**.

## New gateway

1. Enter a name; the code defaults to 4 digits and can be changed.
2. After choosing a zone, click the install point on the floor plan.
3. Optionally enter RSSI at about 1 metre for distance estimates.
4. Client ID can be left blank; the platform generates one.
5. Click **Create and generate provisioning** for host, port, username, password, clientId, publish/subscribe topics, and QoS.

Username and password can be changed in provisioning and saved. The broker comes from the project MQTT connection (the local broker after an offline install). Write these values into the gateway.
