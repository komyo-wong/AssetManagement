# Account

Path: header avatar → **Account** (hidden from the sidebar).

## Profile

**Display name** and **email** (sign-in and password reset). A super admin can change email here. **Avatar** under 240KB; restore default supported. Username cannot be changed here.

## Password

Current password plus new password (min 8 characters) and confirmation.

## Alert preferences

On device offline or a new alert:

- **Popup** (on by default)
- **Sound** (on by default; the browser must receive a click before audio plays)

Custom sound: mp3 / wma, ≤300KB. mp3 is more reliable in Chrome/Safari. Preview or restore the default sound.
