# Overview

Path: **Overview** (default home, pinned tab). Auto-refreshes. Use it to see health; do work on the dedicated pages.

## Metric cards

| Card | Meaning |
| --- | --- |
| Ledger | Non-archived assets; how many are unbound |
| On-site online | Registered beacons + gateways currently online (rate). Unbound assets are not “on site” |
| Offline devices | Offline assets + offline gateways |
| Open alerts | Alerts in **Open** |

## To-dos

Items grouped by offline, unbound, low battery, or alerts, with links to the right screen.

## Offline devices

Separate lists for offline assets and gateways (scroll inside the panel).

## Bottom row

About six recent rows each: last seen, gateway status, recent inventory. Shortcuts to **Floor plan**, **Asset status**, **Alert Center**.
