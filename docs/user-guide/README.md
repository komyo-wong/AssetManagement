# 资产管理平台使用说明书

本说明书依据 **当前已上线功能与侧栏菜单** 编写，覆盖离线安装、登录、各业务页面与平台运维。界面本身支持中/英切换；文档同样提供完整中英版本。

{% hint style="info" %}
将本目录（`docs/user-guide`）设为 GitBook 空间的文档根目录，使用仓库中的 `SUMMARY.md` 作为目录。每个菜单对应独立页面，侧栏分组标题不可点，避免 404。
{% endhint %}

## 导入 GitBook

1. 新建 GitBook 空间，开启 Git 同步或直接上传本文件夹。
2. 文档根目录选择 `docs/user-guide`。
3. 确认识别到 `SUMMARY.md`。侧栏按语言前缀分组（中文 · … / English · …）。
4. 如需两个独立空间：分别把 `zh/`、`en/` 作为根目录，并使用对应语言的 `SUMMARY.md`。
