# 资产管理与物联网平台 — 产品使用说明书

> 适用版本：当前本地开发构建  
> 更新日期：2026-08-13  
> 读者：平台管理员、租户管理员、项目管理员及日常业务用户

---

## 1. 产品简介

本平台面向多租户、多项目的资产与物联网管理场景，覆盖：

- 资产、网关、信标、地图、区域的日常建档与维护
- MQTT 设备接入、扫码定位、告警与盘点
- 平台 / 租户 / 项目三级权限与成员协作
- 项目任务与文档管理

默认开发入口：

| 服务 | 地址 |
| --- | --- |
| Web 管理端 | http://localhost:3006 |
| API | http://localhost:8080 |
| MQTT Worker | http://localhost:8081 |

开发环境超级管理员由 `dev` 引导创建。必须设置环境变量 `DEV_ROOT_PASSWORD`，未配置则不会创建默认管理员。不要把口令写进文档。演示租户/项目代码为 `demo` / `demo-project`。

启动（仓库根目录）：

```bash
./run-api-local.sh
./run-worker-local.sh
./run-web-local.sh
```

## 2. 登录与工作区

### 2.1 登录

1. 打开 Web 管理端登录页。
2. 输入用户名或已验证邮箱与密码。
3. 登录成功后进入总览页；系统按角色加载可见菜单。

若提示超时或网络异常：确认 API（8080）已启动，且前端代理指向正确后端。

### 2.2 租户 / 项目上下文

多数业务数据按「当前租户 + 当前项目」隔离。请先在顶部上下文选择器中选定：

1. 租户
2. 项目

未选择项目时，资产、设备、文档等列表会为空或提示先选择项目。

同一用户可属于多个租户与多个项目；切换上下文后，列表与权限按新上下文重新生效。

### 2.3 退出与会话

通过右上角用户菜单退出。Access Token 过期后会自动要求重新登录。

## 3. 总览

菜单：**总览**

展示当前项目的关键指标（资产、在线网关、开放告警、近期扫码等），用于快速判断运行态势。数据随当前租户/项目变化。

---

## 4. 项目协作

菜单：**项目**

### 4.1 项目列表

- 查看当前租户下的项目。
- 新建项目：填写编码、名称等基础信息。
- 编辑项目资料。
- 归档项目：归档后默认不可作为日常业务工作区使用（可按权限恢复策略执行）。

新建项目时，系统会为项目管理员角色做必要的权限种子初始化。

### 4.2 项目成员

- 邀请成员（按用户名或用户 ID）。
- 为成员分配一个或多个**项目角色**。
- 移除成员。

成员权限以项目角色绑定的权限码为准。

### 4.3 项目角色

在租户/项目权限体系中管理项目级角色（创建、编辑权限集合、删除非系统角色）。系统/受保护角色不可随意删除。

### 4.4 项目任务

登记与更新项目内任务（编码、名称、状态、描述等），用于协作跟踪。

### 4.5 项目文档

- **上传**：选择本地文件，可选填写标题；文件写入服务端本地文档存储。
- **下载**：按列表中的「下载」获取原始文件。
- **删除**：删除元数据并清理已存储文件。

说明：

- 建议单文件不超过配置上限（默认约 50MB，以服务端 `multipart` 配置为准）。
- 仅元数据登记（无实际上传）的历史 stub 记录，下载可能提示文件不存在；请改用「上传文档」。

---

## 5. 租户管理

菜单：**租户**

### 5.1 租户成员

- 邀请用户加入当前租户。
- 分配**租户角色**。
- 移除成员。

租户管理员负责本组织成员与项目边界，不能越权访问其他租户。

### 5.2 租户角色与权限

- 创建自定义租户角色并勾选可委派的权限。
- 编辑权限集合；删除非受保护角色。
- 「权限目录」页用于查阅可用权限码，权限本身只读。

---

## 6. 资产管理

菜单：**资产**

### 6.1 资产列表

- 新建 / 编辑资产（编码、名称、类型、状态等）。
- **绑定信标**：将资产与信标关联后，扫码与定位可映射到该资产。
- **解绑信标**：解除关联。

### 6.2 资产类型

维护资产分类字典，供资产建档时选用。

### 6.3 资产状态

按状态筛选与查看资产运行/业务状态。

### 6.4 盘点

发起盘点会话并查看历史盘点记录，用于现场核对资产在册情况。

---

## 7. 设备与空间

菜单：**设备**

### 7.1 信标（Beacon）

- 建档信标（编码、名称、MAC/标识等字段以表单为准）。
- 查看信标扫码历史（按信标维度）。
- 与资产绑定后，扫码记录可追溯到资产。

### 7.2 网关（Gateway）

- 建档与编辑网关。
- 查看在线状态。
- **Provision**：获取该网关 MQTT 接入相关配置信息，便于现场部署。

平台管理员还可在「平台 → 网关总览」跨项目查看网关。

### 7.3 地图与区域

- **地图**：登记场地地图元数据。
- **区域（Zone）**：划分业务区域，供定位、告警规则等引用。

---

## 8. 定位与点名

菜单：**定位**

### 8.1 实时定位

查看当前项目下近期活跃的定位/扫码结果（依赖网关上报与 Worker 处理）。

### 8.2 轨迹历史

分页查询历史扫码；可按信标过滤。用于回溯设备经过路径或时间点。

### 8.3 点名（Roll Call）

发起点名会话，核对现场应到设备/人员覆盖情况。

---

## 9. 告警中心

菜单：**告警**

### 9.1 告警事件

- 查看开放与历史告警。
- **确认（Acknowledge）**、**关闭（Resolve）** 告警流转。

### 9.2 告警规则

配置规则条件（如离线、越界等，以表单字段为准）。规则生效后由后台根据上报数据触发事件。

---

## 10. 数据分析

菜单：**分析**

- **资产分析**：资产规模与结构类汇总。
- **每日汇总**：近 7 日扫码等关键指标趋势，便于运维巡检。

---

## 11. MQTT 集成

菜单：**MQTT**（需具备连接查看相关权限）

### 11.1 连接配置

为当前项目配置 Broker 连接（主机、端口、认证、TLS 等），并支持连接测试。

### 11.2 Topic 路由

将上行 Topic 模式映射到业务处理类型（如扫码解析），确保 Worker 能正确消费。

### 11.3 消息监控

分页查看近期 MQTT 消息日志，用于联调与排障。

### 11.4 下行命令

填写 Topic 与 Payload，投递下行命令；命令进入 outbox，由 MQTT Worker 实际发布。可在命令列表查看投递状态。

现场设备还需在 Mosquitto（或其他 Broker）侧配置认证与 ACL；开发环境请确保 Worker 与 Broker 可达。

---

## 12. 平台管理（Root / 平台超管）

菜单：**平台**（默认对 Root 可见；其他平台角色需具备对应平台权限）

### 12.1 平台用户

| 操作 | 说明 |
| --- | --- |
| 新建用户 | 用户名、邮箱、初始密码、显示名、平台角色 |
| 编辑 | 修改显示名 |
| 分配角色 | 绑定平台角色编码集合 |
| 重置密码 | 新密码至少 8 位 |
| 激活 / 停用 | 控制账户可用性 |

**保护规则**：Root 与受保护账户不可在此停用、改角色或删除。

### 12.2 平台角色

- 新建 PLATFORM 作用域角色并勾选权限。
- 编辑名称与权限集合。
- 删除非系统、非受保护角色（删除前会解除与用户的绑定）。

### 12.3 平台权限

只读权限目录，供分配角色时参考。

### 12.4 审计日志

查询平台关键操作审计，支持分页。

### 12.5 网关总览

跨租户/项目查看网关清单，便于超管运维。

## 13. 推荐业务流程（快速上手）

1. **Root 登录** → 确认演示租户/项目，或新建租户成员与项目。
2. **项目上下文**中选中目标项目。
3. **设备**：创建网关与信标；网关完成 MQTT provision 与现场接入。
4. **资产**：创建资产类型与资产，并将资产绑定信标。
5. **MQTT**：配置连接与 Topic 路由，确认 Worker 在线；用消息监控验证上行。
6. **定位 / 告警**：查看实时扫码；按需配置告警规则。
7. **协作**：邀请项目成员、分配角色；上传项目文档；登记任务。
8. **平台管理**（可选）：创建其他平台管理员并分配平台角色。

## 14. 权限与可见性说明

- 菜单可见性由角色与权限共同决定；看不到的菜单通常表示当前账户无对应权限。
- API 仍会在服务端二次鉴权；前端隐藏不能替代服务端授权。
- 三级作用域互不替代：平台角色 ≠ 租户角色 ≠ 项目角色。

常见角色心智模型：

| 角色层级 | 典型能力 |
| --- | --- |
| Root / 平台超管 | 平台用户、平台角色、跨项目网关、审计 |
| 租户管理员 | 租户成员、租户角色、项目创建与归档 |
| 项目管理员 | 项目成员、资产/设备/MQTT/告警等业务配置 |
| 项目成员 | 按授予权限只读或有限操作 |

## 15. 常见问题

**Q：登录成功但业务页为空？**  
A：检查是否已选择租户与项目；确认账户在该项目有成员资格。

**Q：MQTT 有配置但无扫码？**  
A：确认 Worker 已启动、Topic 路由匹配、设备已连上 Broker，并用「消息监控」核对是否收到原始消息。

**Q：文档无法下载？**  
A：仅通过「上传文档」写入存储的文件可下载；历史仅元数据记录没有实体文件。

**Q：无法停用某个用户？**  
A：Root / 受保护账户禁止在管理界面停用或改角色。

**Q：删除角色失败？**  
A：系统角色或受保护角色不可删；先确认角色标记。
