第一次使用

按下面顺序做，可避免「网关在线但资产全是未绑定」。

1. 安装并登录

  1. 按 离线安装 装好。
  2. 浏览器打开 http://<服务器IP>/（须与 config.env 里的 PUBLIC_HOST 一致；云主机见 离线安装）。
  3. 用安装结束界面上显示的账号登录（也可事后在服务器 config.env 中查看）。登录提示跨站被拒绝时，按离线安装里的「访问地址」改配置后重启。
  4. 右上角切换 简体中文 / English（会记住偏好）。
首次登录后请到 **个人中心** 修改管理员密码，并填写真实 **邮箱**（找回密码和告警邮件都依赖邮箱）。

2. 确认 MQTT 已就绪

打开 MQTT 接入 → 连接管理，应已有 本机 Broker。

Topic 路由 在安装时已写入，一般不用改、也不必对照规则表。网关参数请从 网关管理 → 接入配置 复制。

3. 空间：地图 → 区域 → 网关

  1. 设备与空间 → 地图管理：上传楼层图，填写真实长宽（米）。
  2. 区域管理：区域必须归属一张地图。
  3. 网关管理 → 新建网关：创建后生成 MQTT 接入配置，把页面上的 host、端口、账号、密码、Topic 写入网关。
  4. 选择区域后在平面图上点安装位置，可填 1 米校准 RSSI。

接入说明见 网关接入参数。

4. 登记信标并建资产

  1. 信标管理：按 MAC 添加或 CSV 导入。只有登记过的 MAC 才会入库。
  2. 资产类型：先建分类（如「电脑」「工装」）。
  3. 资产管理：新建资产并 绑定信标。未绑定显示「未绑定」，无法按信标定位。

5. 在线与告警

  1. 在线阈值：网关默认约 90 秒，信标/资产默认约 300 秒。
  2. 告警规则：按需开启离线、低电、弱信号、盘点结果。
  3. 平台管理 → 邮件配置：配好 SMTP 后，「忘记密码」和邮件通知才能真正发出。
  4. 我的通知：添加邮箱或 Webhook，订阅告警/恢复。

6. 日常作业

目标 去哪里
看现场是否健康 总览、资产状态
找某台资产 资产管理 蜂鸣；平面图看邻近位置
改墨水屏 资产列表「改屏」
盘点一批资产 盘点管理，选网关与范围后开始点名

权限说明

  • 普通业务菜单：具备对应权限的登录用户可见。
  • 平台管理 整组菜单：仅 超级管理员。
  • 超级管理员不能在「用户管理」里被改停用；改邮箱请走 个人中心。

现场 App 对接同一套 HTTP API：登录须带 client=mobile，清单与用法见 App 接口。
