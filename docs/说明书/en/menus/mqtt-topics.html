Topic routes

Path: MQTT Integration → Topic routes.

Access rules are created during offline install. Do not change them, and do not publish the rule list. Copy publish/subscribe topics from Gateways → Provisioning.

Add or edit routes only when vendor or implementation staff ask you to. Overlapping routes on the same connection cannot both be enabled. Downlink publish topics cannot contain wildcards.
